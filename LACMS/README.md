# Legislative Agenda and Calendar Management System

Project folder: `lacms`

Local path:

```text
C:\xampp\htdocs\lacms
```

Local URL:

```text
http://localhost/lacms
```

## Main modules

1. Legislative Priority Setting
2. Calendar Scheduling
3. Meeting Coordination
4. Deadline Tracking
5. Executive-Legislative Synchronization

## Current phase

Navigation and client-ready user interface first. Database write operations,
AJAX endpoints, workflow automation, and integrations will be connected later.
